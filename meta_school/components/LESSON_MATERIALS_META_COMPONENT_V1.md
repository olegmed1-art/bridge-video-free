# Учебные материалы → META Component v1.0

Status: A1_GATE_CANDIDATE

## Канонические источники
1. `Курс Бридж - Конспект. Правки.` — основной источник содержания курса, системы торговли и утверждённых формулировок.
2. `Bridge Template.pptx` — основной шаблон презентационных материалов, когда задача требует презентацию по шаблону.
3. Прямые правки владельца для конкретного занятия/материала имеют приоритет.

META не дополняет отсутствующее правило торговли или методику собственным предположением.

## DISCOVER / BASELINE
Курс содержит последовательность занятий, включая отдельные темы «Введение в торговлю», «Продолжение торговли», «Конкурентная торговля», интервенцию и другие разделы. Часть курса завершена, часть находится в работе; статус исходника сохраняется и не трактуется как ошибка.

Baseline-классы:
- точное воспроизведение утверждённого содержания;
- техническое форматирование/экспорт;
- сохранение структуры занятия;
- упражнения, прямо выводимые из утверждённого материала;
- запрос, для которого в материалах нет нужного правила -> UNKNOWN/ASK_OWNER, а не выдумывание;
- изменение системы торговли/методики -> R4 OWNER_REVIEW;
- пользовательская правка -> новый приоритетный канон для заданного scope.

## COMPONENT CONTRACT
Primary metrics:
- canon_fidelity — смысл материала не расходится с источником;
- terminology_fidelity — используется терминология школы, включая «торговля»;
- source_coverage — каждое каноническое утверждение имеет источник/owner instruction;
- requested_scope_completeness — выполнены все запрошенные блоки;
- layout_fidelity — соблюдён требуемый шаблон/геометрия;
- export_integrity — итоговый PPTX/PDF/DOCX открывается, не обрезан и визуально проверен;
- provenance — сохранены источник, версия/идентификатор и преобразования.

Guardrails:
- не придумывать систему торговли;
- не придумывать методику преподавания;
- не превращать предложение META в канон;
- не менять исходные учебные материалы автоматически;
- не удалять исходники;
- не подменять точную правку пользователя «улучшенной» формулировкой без основания;
- термин «аукцион» не использовать в новых русскоязычных материалах школы; использовать «торговля»;
- техническая оптимизация макета не должна менять учебный смысл.

Risk mapping:
R0 — чтение/QC/сравнение;
R1 — детерминированное форматирование, экспорт, геометрия, исправление опечатки/терминологии без изменения смысла;
R2 — общий генератор/шаблон/пайплайн, влияющий на множество материалов;
R3 — права доступа, персональные данные учеников, production DB;
R4 — система торговли, методика, канонические объяснения и учебные правила.

## ADAPTER EVENT
`event_id, run_id, material_type, source_ids, source_versions, owner_instruction_id, topic, lesson_id, requested_format, template_id, canon_claims, proposal_claims, terminology_checks, layout_checks, export_checks, qc_status, evidence_ids, output_hash`.

`canon_claims` и `proposal_claims` хранятся раздельно. Предложение не может автоматически перейти в canon_claims.

## SHADOW / FAILURE MATRIX
S1: техническая опечатка без изменения смысла -> Candidate.
S2: незавершённый раздел курса -> NO_CHANGE, если исходник так и помечен.
S3: попытка автоматически «дописать» отсутствующее соглашение торговли -> REJECT/ASK_OWNER.
S4: изменение методики -> OWNER_REVIEW R4.
S5: противоречащие правки/источники -> CONFLICTED/RETEST.
S6: изменившийся исходник после freeze -> REBASE_REQUIRED.
S7: экспорт создан, но read-back/рендер не подтверждён -> UNKNOWN/BLOCK DONE.
S8: общий шаблон меняет много материалов -> escalate R2.
S9: красивый макет теряет текст/карты -> guardrail FAIL.
S10: META предлагает новую формулировку -> PROPOSAL only, не канон.

## A1 GATE
A1 разрешает автономные QC, Candidate, технические sandbox-преобразования и regression в изолированной области.
A1 не разрешает изменение исходного конспекта, Bridge Template или канонического содержания.
A2 не выдан.
