# Непрерывный контроль качества

Автоматический контроль должен регулярно проверять последние production runs, распознавание, семантический QC, визуальный анализ, мастер-PDF и известные проблемные бриджевые фразы. Безопасные улучшения можно внедрять автономно по схеме archive -> new revision -> validation -> promote/rollback. Пользователь уведомляется только о существенном подтверждённом улучшении, критической проблеме или откате.
