# INGEST-0010 — Next gate

Date: 2026-08-27

Before any rule activation, each PDF block must be converted into an atomic candidate with:
- exact auction path;
- acting partnership role;
- hand conditions stated by the source;
- call/action;
- meaning, forcing and alert semantics only where stated;
- public inferences no stronger than the source;
- page/block provenance;
- positive, negative, boundary and interference tests.

Any missing element remains unknown or becomes a knowledge gap. External systems may test the interpretation but cannot fill it silently.
