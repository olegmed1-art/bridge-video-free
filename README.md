# bridge-video-free

Для бридж-профилей Universal Video формирует хэшированный пакет соседних кадров, а восстановление раздачи выполняется отдельным fail-closed этапом Bridge Vision. Контракт и схема: [docs/architecture/BRIDGE_FRAME_EVIDENCE_PIPELINE_V1_RU.md](docs/architecture/BRIDGE_FRAME_EVIDENCE_PIPELINE_V1_RU.md).

Production API deploys automatically to Vercel from the `main` branch.
