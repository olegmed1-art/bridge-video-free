# Version registry — Bridge Video 3.1 FREE

Пользовательское имя продукта остаётся **3.1 FREE**. Каждое изменение, влияющее на поведение алгоритма, получает новую внутреннюю `algorithmRevision` и отдельную запись в этом каталоге.

Статусы:
- `candidate-validation` — новая ревизия проходит проверку;
- `stable` — подтверждена на production-проверках и может быть точкой отката;
- `rejected-regression` — сохранена для разбора, но не используется;
- `rolled-back` — была активна, затем выполнен откат.

Перед началом новой ревизии последняя стабильная версия должна быть сохранена в архивной ветке `archive/...`. Исходные пользовательские файлы и их права при этом не меняются.
