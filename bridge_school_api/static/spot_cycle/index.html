Сколько взяток?

♦

Найди лучший план и оцени, сколько новых взяток можно гарантировать бубновой фоской стола.

  • В бубнах уже сыграны 2, 3, 4, 8.
  • По условию оставшиеся бубны защиты разделены 2–2. Какие именно карты у каждого защитника, неизвестно.
  • Считай только 9–13-ю взятки, против любой допустимой защиты. Первые восемь взяток не считаем.
  • Нужна взятка именно фоской ♦7, ♦6 или ♦5 стола. Снос фоски на взятку руки не считается.
