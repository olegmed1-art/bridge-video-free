# Universal Video: тестовый алгоритм разделения спикеров v2

Статус: локальный кандидат, shadow/evidence-only. Он не определяет реальные личности и не активирует Канон.

## Результат аудита предыдущего теста

Тест commit `f15e1c7` подтверждал вызов стадии и целостность файлов, но пропускал три опасные ситуации:

1. Метка могла сохраняться при итоговом статусе `UNAVAILABLE`.
2. Входные Zoom/diarization labels могли содержать реальные имена, хотя отчёт заявлял анонимность.
3. Результат diarizer мог заменить исходный текст ASR, а verifier принимал изменённый текст как обычную расшифровку.

Также verifier допускал произвольную строку в `speaker`, не требовал два независимых кластера для `PASS` и не связывал cluster counts с фактическими сегментами.

## Алгоритм v2

1. Скопировать исходные ASR-сегменты и удалить из копии любые старые speaker-поля.
2. Запустить локальный optional diarizer во временной директории.
3. Не принимать от diarizer текст, таймкоды, chunk или reliability — читать только speaker-аннотации.
4. Проверить допустимый status, неизменное число сегментов и структуру каждой аннотации.
5. Проверить конечные confidence в диапазоне `0..1`.
6. Отклонить результат без меток, с одним кластером, более чем с восемью кластерами или с неполной аннотацией.
7. Переназвать все исходные labels по порядку первого появления в `SPEAKER_A..H`. Исходные labels не сохранять.
8. `teacher/student` хранить только как `SUGGESTION_ONLY` и только при отдельном `DIARIZED_ROLE_MAPPED`; иначе роль `unknown`.
9. При любом отказе удалить все speaker-поля и сформировать `INCONCLUSIVE` с bounded reason code.
10. Записать `speaker_diarization.json`; verifier пересчитывает labels/counts по `transcript.jsonl`, проверяет privacy boundary и связывает хеш отчёта с evidence-export.

## Границы PASS

- минимум два анонимных кластера;
- labels только последовательные `SPEAKER_A..H`;
- каждая размеченная реплика имеет полный набор speaker-полей;
- cluster counts точно совпадают с расшифровкой;
- ASR-текст и таймлайн сохранены;
- реальные имена, аудио и embeddings отсутствуют;
- named identity не заявляется;
- результат не публикуется и не меняет Канон.

## Тестовая матрица

- два корректных кластера и role mapping;
- повторная анонимизация исходных имён;
- сохранение исходного ASR при попытке его изменить;
- collapse в один кластер;
- неизвестный status;
- несовпадение числа сегментов;
- NaN/некорректный confidence;
- реальное имя в итоговом bundle;
- повреждённые counts/privacy/report fields;
- large-lesson fixture формы 980/934, coverage 0.9531;
- evidence-gap regression для «Дианы 2»: публичные cluster counts 308+646=954 относятся не к тем же единицам, что 934 labeled ASR-сегмента, поэтому без raw speaker map полевой эталон не воспроизводим.

Полевая готовность требует raw speaker map, отдельного запуска на новом видео и ручной эталонной выборки. Unit/contract PASS не доказывает корректность границ реплик на «Диане 13».
