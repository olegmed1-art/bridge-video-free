# Autopilot role-dispatch mailbox v4

This draft pull request is a durable, open GitHub conversation target for
production Autopilot role dispatches.

## Contract

- Keep this pull request open and draft while it is the active mailbox.
- Do not merge or close it until a later mailbox is active in production.
- The mailbox contains no executable or production change.
- Every command remains bound to its dispatch ID, epoch, role, target PR,
  exact head SHA, and task fingerprint.
- Delivery is accepted only from an owner-authenticated `@codex execute this task`
  command and the pinned Codex GitHub App identity.
- Capacity and rotation remain enforced by the Neon control plane.
