# Bridge School architecture documents

This directory contains versioned architecture and implementation checkpoints for the School/Club platform. Production database changes remain governed by the repository migration and `database-production` promotion workflow.

## Current top-level model

Start with [simple_operating_architecture_v1.md](simple_operating_architecture_v1.md) for day-to-day architectural decisions:

> Codex coordinates, GitHub controls, Oracle computes, Neon and Drive store, Vercel shows.

Detailed subsystem documents remain valid only inside that five-block model.
