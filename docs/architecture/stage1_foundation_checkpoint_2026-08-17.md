`Source -> SourceAsset/Evidence -> Deal -> AnalysisRun/Input -> RunCheckpoint -> OutputAsset -> Artifact -> ArtifactVersion -> AnalysisRunOutput`

The test asserts that:

- the Deal points to the exact Source ID;

- all test facts are rolled back after verification.

This gate avoids name/folder inference and proves the canonical identity/provenance path at database level.
